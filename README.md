# Amortized Branching Program Simulators

[English](README.md) | [简体中文](README.zh-CN.md)

Two independent, interactive research and teaching aids live in this repository. Each simulator has its own source, dependencies, and local build commands.

| Simulator | Focus | Live page | Source and instructions |
| --- | --- | --- | --- |
| Potechin | Shared-network construction for amortized branching programs, shown at $n=2$ | [Open Potechin](https://therisnow.github.io/amortized-branching-program-simulator/) | [PotechinSimulator/](PotechinSimulator/) |
| Cook–Mertz | Theorem 11 / Algorithm 3: blockwise transparent registers, output updates, and Gray-code scheduling, shown at $n=4,k=2$ | [Open Cook–Mertz](https://therisnow.github.io/amortized-branching-program-simulator/cook-mertz/) | [CookMertzSimulator/](CookMertzSimulator/) |
